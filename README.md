# 猫猫sama 个人网站

🦊 深色 AI 科技感 + 和风暖狐主题的个人介绍站。

- **品牌**:猫猫sama
- **域名**:仙狐大人.我爱你
- **技术**:纯静态 HTML / CSS / Vanilla JS,零依赖、零构建
- **双语**:中文 / 日本語 一键切换
- **图标**:570+ Icons 库(个人/商业免费,无需署名)

## 本地预览

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 页面结构

1. Hero — 头像、标题、简介、标签
2. 关于 — 自我介绍
3. 技能 — Python / AI·LLM / Godot
4. 项目作品 — ClipCapture、maomaobot、《未曾看见的你》
5. 联系 — 邮箱一键复制

## 文件

```
index.html          页面结构与内联 SVG 图标
css/style.css       全部样式与动效
js/main.js          双语切换、滚动渐入、交互
assets/             头像、图标资源
```
